# С чего начать

1. Загрузи содержимое этой папки в корень своего репозитория GitHub. Настоящий токен бота в файлы не вставляй.
2. Подключи репозиторий к постоянно работающему серверу. Готовый вариант — Render Blueprint через `render.yaml`: он создаёт **платный** сервис и постоянный диск. Проверь стоимость перед созданием.
3. В секретных настройках сервера задай `BOT_TOKEN`, `APP_URL` и `ALLOWED_TELEGRAM_ID`. Для базы на Render используется `DATABASE_PATH=/var/data/gifts.sqlite` и диск `/var/data`.
4. Если ID получателя неизвестен: временно не задавай `ALLOWED_TELEGRAM_ID` при ручной настройке сервиса, пусть Бусенька отправит боту `/id`, затем внеси её ID и перезапусти сервис. Подарки до этого закрыты.
5. В Shell сервиса выполни `npm run bot:setup`, затем перезапусти сервис. Скрипт переключает бота на long polling и добавляет команды и кнопку приложения.
6. В BotFather включи Main Mini App своего бота и укажи HTTPS-ссылку сервиса — ту же, что в `APP_URL`.
7. Бусенька отправляет боту `/start` и открывает приложение из Telegram. После этого работают уведомления. Первое настоящее нажатие расходует первый подарок.

Правила: 15 открытий, максимум одно в день по Москве, строго 20 000 ₽ за серию, одна «Фигушка». Пропущенные дни не расходуют подарки. После завершения новая серия сама не начинается. Банковские переводы не подключены.

Без настройки сервера, токена и получателя настоящий Telegram-режим не заработает. Для локальной проверки внешнего вида без сообщений есть `npm run demo` с отдельной тестовой базой.

Подробная инструкция, Docker, резервные копии и диагностика находятся в README.md.
